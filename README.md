### Featured Work

- **QueryVoice &mdash; Speech-to-SQL Agentic Platform**  
  Voice-driven natural language to SQL translation system with 99% execution accuracy. Built with LangGraph hierarchical RAG, autonomous self-correction loops, QLoRA fine-tuned Qwen-7B, ChromaDB, FastAPI, and Docker.

- **AST AI Security & Static Code Auditor**  
  Static analysis engine that parses Python ASTs to detect insecure deserialization sinks, unvalidated execution vectors, prompt injection attack surfaces, direct model weights tampering, and pipeline privilege escalations in ML backends.

- **Hyper-Realistic AR Culinary Platform (3DGS)**  
  High-fidelity interactive WebAR reconstruction pipeline using 3D Gaussian Splatting, GLOMAP/COLMAP structure-from-motion alignment, and Three.js optimization for lightweight mobile browsers.

- **TrackChild &mdash; Motion Detection & Multi-Object Re-ID**  
  Edge-ready computer vision monitoring system leveraging YOLO, ByteTrack, Vision Transformers, and deep appearance embeddings with persistent tracking through occlusions.
