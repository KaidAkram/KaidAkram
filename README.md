### 🏆 Key Engineering & Research Highlights

- **QueryVoice — Speech-to-Text to SQL Agentic Platform** *(Production Architecture)*  
  Voice-driven BI platform converting natural speech into verified SQL queries with 99% execution accuracy. Autonomous LangGraph agent with hierarchical RAG, self-correction loops, Qwen-7B fine-tuned via QLoRA, ChromaDB, FastAPI, and Docker.
- **AST AI Security & Static Code Auditor** *(Security Research)*  
  Specialized static code analysis engine parsing Python ASTs to detect insecure deserialization sinks, unvalidated execution vectors, prompt injection vectors, direct model weights tampering, and pipeline privilege escalations.
