# Security Policy

## Reporting Security Vulnerabilities

If you discover a potential security vulnerability within any project or research code in this repository, please report it privately:

- **Security Contact:** akram.kaid.engineer@gmail.com
- **PGP/Encrypted Communications:** Available upon request

Please include:
1. Description of the issue and potential impact
2. Steps to reproduce or proof-of-concept
3. Relevant environment details
